# Experimental data

Raw data are not included. See [the data layout guide](../docs/DATA_LAYOUT.md).

Put experiment folders under `data/aqueous/` and `data/gas/`, or edit `scripts/repo_config.py` to point to recordings elsewhere. Existing derived inputs can go under `data/derived/`, as specified there. Generated results belong under `outputs/` and `cache/`, not in the raw data roots. Data files are excluded from Git by default.
